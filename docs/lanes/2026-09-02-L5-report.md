## Delivered behavior

`facts_for()` keeps one finding's public facts and zygosity class. It excludes genotype, call quality, file names, job identifiers, and other findings.

The cache key covers the prompt version, backend, model, mirror version, variant facts, sorted condition identifiers, and zygosity class.

The prompt limits drafts to 180 words. It requires plain language, active voice, present tense, grounded claims, and evidence-chain citations.

The post-check refuses alarm language, diagnosis wording, banned constructions, excessive length, missing citations, and unknown citations.

The OpenAI-compatible backend reads its key file at call time. It refuses a key file whose mode differs from `0600`.

The Codex and Claude CLI backends require both worker-side enablement and an administrator-approved job choice.

Rejected drafts and backend failures never enter the cache. Cache-only and budget-limited findings also create no cache entry.

The inline path reads accepted cache entries only. The queued worker drafts after analysis and before all exports render.

The systemd unit documents every new setting. It leaves `DNAREPORT_EXPLAIN_ENABLED` unset.
