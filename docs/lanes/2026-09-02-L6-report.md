## Delivered behavior

### EWAS aggregation

Repeated marker-trait rows now become one finding before interpretation.

The finding keeps the strongest tier, smallest p-value, study count, participant total, PMIDs, tissues, and direction agreement.

Interpretation states the study count, participant count, direction agreement, and tissue context when those fields exist.

Missing tissue support stays unknown. It does not become a negative claim.

### ClinGen snapshot

The builder discovers the header row after any CSV or TSV preamble.

It stores gene-disease validity, inheritance, adult and pediatric actionability, report links, schema version, and retrieval date.

Condition copy prefers matching ClinGen inheritance before the reviewed fallback table.

Evidence chains show ClinGen validity and numeric actionability when those fields exist.

ClinVar pathogenic findings enter rule A-prime only when the adult actionability score reaches nine.

The deployment refresh path registers `clingen` in the builder, publisher, NAS sync, worker dispatcher, and monthly timer.

### PharmCAT and CPIC

The worker image definition pins PharmCAT 3.4.0, Java 17, and bcftools 1.24.

Sequencing reports call PharmCAT once and delete its temporary output after parsing.

Only complete gene, diplotype, and phenotype records enter CPIC selection.

CPIC recommendations use an exact phenotype match for the named gene.

The resulting finding keeps the known diplotype, phenotype, activity score, caller, recommendation, classification, and CPIC level.

Array reports never call PharmCAT.

They state: “Pharmacogenomic guidance is by gene only: this file type does not support diplotype calling.”

Workers without PharmCAT retain gene-level guidance and state that PharmCAT is unavailable.
