# HG002 public Nanopore reference demo

`/demo/hg002` serves a precomputed report from Oxford Nanopore's public
GIAB 2025.01 SUP HG002 / GM24385 run, flowcell PAW70337. It uses real
published VCF and bedMethyl measurements from a cultured lymphoblastoid cell
line. It makes no personal health, age, lifestyle or pharmacogenomic prediction.
The small `/demo/nanopore` fixture remains available for deterministic tests.

## Rebuild

Install DNA-Report with its pinned engines. Supply local full ClinVar and EWAS
SQLite mirrors. Use an empty output directory; rebuilding is an offline operator
command, never part of a public request or an uploaded-data job.

```sh
python -m dnareport.reference_dataset --fetch \
  --inputs /data/hg002-inputs --output /data/hg002-staging \
  --clinvar-mirror /mirrors/clinvar_mirror.db \
  --ewas-mirror /mirrors/ewas_mirror.db
```

The optional fetch downloads approximately 1.75 GB, checks pinned SHA-256 and
length, and requires all four matched input objects. SHA-256 values record our
acquisition, not a publisher signature. The generic VCF `SAMPLE` label is bound
to HG002 by the exact release/flowcell manifest and reference header. No raw-read
CRAM/POD5 or models are downloaded. The command streams every source row, retains
only EPICv2-mapped CpGs in memory, and queries local reference mirrors only.

## Scope and outputs

- HP1, HP2 and ungrouped are disjoint read partitions. Sum integer modified,
  canonical and other-modification counts before applying minimum coverage 5.
  Ungrouped alone is not a whole-sample methylome. Only `m` is reported as 5mC;
  confident other modifications remain in the valid-call denominator.
- `HG002.cpg-measurements.tsv.gz` includes **all unambiguous EPICv2-mapped
  targets**, including low-coverage and missing rows, with per-partition counts.
  It is not every genomic CpG. Original genome-wide bedMethyl files are linked
  in provenance. Missing fractions remain blank; measured zero remains zero.
- Every VCF record is visited. Screen autosomal PASS diploid carried small
  alleles (ACGT only, maximum allele length 50), DP >= 10 and GQ >= 20 against
  the full local ClinVar mirror. Keep records whose significance contains
  `pathogenic`, including conflicting labels. The variant archive contains
  these retained findings, not all ClinVar overlaps or all variants. This is
  not a negative screen for excluded/unreported variants.
- `HG002.associations.tsv.gz` contains every EWAS mirror row matching a
  qualifying measured CpG, including rows not selected for browser display.
- The browser shows one leading CpG for each of up to 1,000 non-covariate raw
  EWAS traits, ranked by evidence tier, p-value, study size and stable IDs. All
  studies for a selected CpG/trait remain attached. These are research
  associations, not 1,000 independent diagnoses or inferred phenotypes.
- JSON, Markdown, HTML and provenance include the scope, actual counts,
  processing thresholds, acquisition manifest and reference-mirror hashes.
  `artifact-index.json` records every public file's size and SHA-256 and is
  written last. Intermediate caches and source inputs are never served.

## Install and verify

Copy only the seven files listed in `artifact-index.json` plus the index into
an immutable staging directory on the results volume. Verify their SHA-256s
there before atomically installing the directory as `/results/public-demo/hg002`
(or set `DNAREPORT_HG002_DEMO_DIR`). Do not overwrite a live dataset in place.
The home page and health advertise HG002 only when the complete allowlisted
artifact set exists with matching sizes. Requests do not rehash the 200 MB
association archive. No authentication is required for these public reference
artifacts; ordinary uploads and private result exports keep their existing rules.

Check `/health`, `/demo/hg002`, JSON/Markdown downloads, file download headers,
and both light/dark themes after deploying the app. The report is served from
reviewed files and does not rerun the analysis on each visit.

## Provenance and next validation

Source: [Oxford Nanopore GIAB 2025.01](https://epi2me.nanoporetech.com/giab-2025.01/).
Oxford Nanopore Technologies Benchmark Datasets are listed as **CC BY-NC 4.0**
in the [dataset registry](https://registry.opendata.aws/ont-open-data/).
Our derived outputs pool partitions, filter calls, map CpGs and attach reference
annotations; retain this attribution and the original data terms when reusing them.
The [NIST Genome in a Bottle project](https://www.nist.gov/programs-projects/genome-bottle)
describes the reference materials and benchmark resources.

This validates published-output ingestion/reporting only. Native read-level
validation still requires a configured ONT worker, compatible reference and
models, comparison with a versioned HG002 truth set inside its confident regions,
and independent methylation agreement checks. The personal pilot also needs
actual extraction/library QC and instrument measurements. No laboratory or
clinical validation is implied by a successful demo build.
